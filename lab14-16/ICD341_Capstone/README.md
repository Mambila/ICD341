# Statistical Analysis and Visualization of Maize Production in Zambia Using Python

## Overview
ICD341 Advanced Statistical Computing Capstone Project analyzing maize production across Zambian districts using descriptive statistics, linear regression, and an interactive Streamlit dashboard.

## How to Run
1. Install dependencies: pip install -r requirements.txt
2. Run analysis & generate data/graphs: python src/analysis.py
3. Launch dashboard: python -m streamlit run dashboard/app.py
